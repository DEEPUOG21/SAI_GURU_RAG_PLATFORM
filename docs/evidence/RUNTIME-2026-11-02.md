## Functional and source verification

- [The validated application commit](https://github.com/DEEPUOG21/SAI_GURU_RAG_PLATFORM/commit/840a322) passed 284 backend tests, frontend checks, CodeQL, source security scans and container builds.
- The container job also checked Python 3.11, UID 10001, the ONNX CPU provider and a real isolated parser subprocess. This verifies the native runtime and parser path, not model answer quality.
- The frontend unit run passed 15 tests; the CI frontend job also ran its configured Playwright checks.
- Eleven moderate frontend toolchain advisories remain. The HIGH/CRITICAL image result does not erase those advisories.
- No new answer-quality benchmark or independent human score was produced by this work.

## Deployment boundary

Green CI proves the checked source and images passed their configured checks. It does not prove Render deployed them. `GET /api/v1/health` now exposes Render's non-secret commit SHA as `revision`; compare the live value with the intended source commit. A response without the field is from an earlier application version. A `null` revision means the running host did not provide the metadata. Database readiness and real provider calls require separate checks.

At the final check for this report, the hosted API was healthy but still returned the earlier health response without `revision`. The new Render deployment therefore remained unverified. Production visual browser verification and the user's independent 20-answer review also remained pending.
